# Contributing to Scrapefix

Thanks for helping! 

1. Fork the repo and create a branch: `git checkout -b feat/my-change`
2. Install: `bun install`, run: `bun run dev`
3. Keep TypeScript strict and lint clean (`bun run lint`)
4. Use design tokens from `src/styles.css` — no raw colors
5. Every new table needs `owner_id`, owner-only RLS and explicit GRANTs
6. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`)
7. Open a pull request describing what and why

Report bugs with steps to reproduce, expected vs actual behaviour, and screenshots.
