# User Guide

| Page | What it does |
| --- | --- |
| Overview | 14-day chart of failures vs fixes, top failure reasons, latest failures |
| Scraper jobs | List the sites you scrape; see failures per job |
| Fix queue | All failed records — filter by status and reason |
| Record review | See the error, fill in missing fields, approve or reject |
| Clean data | Approved records, search, CSV export, Google Sheets |
| Connect scraper | Your personal key and copy-paste Python code |
